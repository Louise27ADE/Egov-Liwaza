# AI Usage Disclosure

As required by the LIWAZA assessment, this document discloses all AI tools used,
the prompts submitted, which parts were AI-assisted, and which parts were manually
verified or written.

---

## AI Tools Used

- **Claude Code (Anthropic)** — primary AI assistant for code generation, architecture,
  documentation, and debugging throughout the assessment.
- **Google Gemini 2.5 Flash Lite** — LLM used at runtime inside the product itself
  for natural language understanding and MCP tool orchestration.

---

## Key Prompts Used During the Assessment

Below are the representative prompts submitted to Claude during development:

1. *"Build a Python FastAPI MCP server with 5 tools for Ivorian fiscal services: TVA calculation, CNPS contributions, NIF verification, DGI deadlines, and tax regime info. Use real data from CGI 2024."*

2. *"Integrate Google Gemini 2.5 Flash Lite as the LLM with function calling for MCP tool orchestration. The API key must stay server-side only."*

3. *"Build a React + TypeScript + Tailwind CSS v4 conversational frontend that connects to the FastAPI backend. No sidebar, clean minimal interface."*

4. *"Write a Dockerfile for HuggingFace Spaces deployment (port 7860, non-root user) and a GitHub Actions CI/CD pipeline."*

5. *"Add security: rate limiting 20 req/min per IP, CORS restricted to Vercel domain, input validation with Pydantic, hide /docs in production."*

6. *"Write unit tests with pytest covering all 5 MCP tools including edge cases."*

7. *"Write ARCHITECTURE.md with architecture diagram, deployment topology, and scalability analysis from 100 to 100,000 users."*

8. *"Write AI_STRATEGY.md comparing GPT-4.1, GPT-4o, Claude Sonnet/Opus, Gemini 2.5, Llama, Mistral on quality, cost, latency, privacy, GDPR."*

## Parts Manually Verified or Owned

- **TVA rate 18%** — cross-referenced against Article 339, Code Général des Impôts CI
- **CNPS rates** — verified against official CNPS 2024 schedule:
  employer (5.4% + 2% + 5.5%), employee (3.6%), ceiling 45× SMIG = 3,375,000 FCFA
- **NIF format** — validated against DGI CI official examples
- **Tax regime thresholds** — MICRO (< 50M FCFA), RSI (50M–200M FCFA), RNI (> 200M FCFA)
  verified against CGI CI
- **All architectural decisions** — monorepo choice, LLM selection, deployment platform,
  security design, design system iterations
- **All 6+ UI design iterations** — I directed and rejected multiple versions until the
  design met professional standards
- **Deployment troubleshooting** — HuggingFace git issues, Gemini model selection,
  CORS configuration — solved manually
